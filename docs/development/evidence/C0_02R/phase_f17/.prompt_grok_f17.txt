## 1. Architecture Requirements in `src/resolve/exspander.rs`

### A. Define `HopClass` and `classify_hop`
Define private enum:
```rust
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
enum HopClass {
    Live { edge: GraphEdge, sep: i64, shadow: bool },
    Probe { edge: GraphEdge, sep: i64, shadow: bool },
    SafePrune,
    Inadmissible,
    Unresolved,
}
```

Implement private function `classify_hop`:
```rust
fn classify_hop(
    graph: &CdbgGraph,
    u: DirUnitigId,
    v: DirUnitigId,
    sep_u: i64,
    visited: &[u32],
    step_depth: usize,
    shadow_u: bool,
    curr_dir: DirUnitigId,
    ext_nodes: &HashSet<u32>,
    used_unique: &HashSet<u32>,
    consumed_nodes: &HashSet<u32>,
    max_separation: i64,
    beta: i64,
) -> HopClass {
    // 1. Edge resolution
    let EdgeResolveResult::Valid(edge) = resolve_edge_between(graph, u, v) else {
        return HopClass::Inadmissible;
    };

    // 2. Separation arithmetic: at initial targets (step_depth == 0), sep_u is init_sep.
    // For subsequent steps (step_depth >= 1), add len(u) - overlap.
    let sep_v = (if step_depth == 0 {
        sep_u
    } else {
        sep_u + graph.nodes[u.id() as usize].seq_len as i64
    }) - edge.overlap_k as i64;

    // 3. Window Bound with beta floor:
    if sep_v + beta > max_separation {
        return HopClass::SafePrune;
    }

    // 4. Upstream deletion check:
    let v_node = &graph.nodes[v.id() as usize];
    if v_node.is_deleted && !consumed_nodes.contains(&v.id()) {
        return HopClass::Inadmissible;
    }

    // 5. Circular policy:
    if v_node.is_circular {
        return HopClass::Unresolved;
    }

    // 6. Long unique-node restriction (>= 500 bp):
    if v_node.seq_len >= 500 && (ext_nodes.contains(&v.id()) || visited.contains(&v.id())) {
        return HopClass::SafePrune;
    }

    // 7. Shadow status inheritance:
    let shadow_v = shadow_u
        || (v_node.is_deleted && consumed_nodes.contains(&v.id()))
        || (v_node.seq_len >= 500 && used_unique.contains(&v.id()));

    // 8. Short repeat recurrence (< 500 bp in visited):
    if v_node.seq_len < 500 && visited.contains(&v.id()) && step_depth >= 1 {
        return HopClass::Probe {
            edge,
            sep: sep_v,
            shadow: shadow_v,
        };
    }

    // 9. Default: Live expansion
    HopClass::Live {
        edge,
        sep: sep_v,
        shadow: shadow_v,
    }
}
```

### B. Beta Distance Floor `beta(curr)`
Compute `beta` for `curr_dir`:
```rust
let beta: i64 = matrix
    .links
    .iter()
    .filter(|((u1, _), _)| *u1 == curr_dir)
    .flat_map(|(_, evs)| evs.iter().map(|ev| ev.dist_u1_exit as i64 + ev.dist_u2_entry as i64))
    .min()
    .unwrap_or(0);
```
