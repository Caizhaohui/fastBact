  4. Find `rev_max_support = rev_matching_edges.iter().map(|e| e.support).max().unwrap_or(0)`.
  5. Retain reverse edges with `support == rev_max_support`.
  6. If count != 1, return `None` (reverse tie rejection).
  7. Require:
     - `rev_matching_edges[0].overlap_k as usize == chosen_ov` (reciprocal overlap equality)
     - `rev_max_support == chosen_support` (reciprocal support equality, matching production line 1156!)
