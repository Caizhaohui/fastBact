## Detailed Audit Mandates

### 1. Audit A — Mathematical Soundness of Evidence Floor β(curr) (Highest Priority)
The safe pruning condition in `src/resolve/exspander.rs` is:
`sep_u + beta(curr) > max_insert => HopClass::SafePrune`

Independently prove or disprove:
For every path pruned as `SafePrune`, and for any reachable legal candidate endpoint $v$ satisfying current candidate scoring contracts:
$$\text{span}(v) \ge \text{sep}_u + \beta(\text{curr})$$

#### A1. Evidence Domain
1. Which exact `ReadPairEvidence` entries does `separation_beta` examine?
2. Does it inspect all possible candidate evidence originating from directed `curr_dir`?
3. Could any candidate with smaller implied fragment span be missed due to pre-filtering?
4. Are read endpoint anchors ($p_1, p_2, r_1, r_2$) consistent between `separation_beta` and `score_candidate_path`?
5. Does read orientation or twin mapping affect $\beta$?
6. Do shadow candidates through consumed nodes follow identical distance semantics?
7. Can $\beta$ be artificially inflated by caching, stale data, or edge deduplication?
8. How is $\beta$ handled when no evidence exists anchored at `curr_dir`? Does $\beta = 0$ safely degenerate?

#### A2. Coordinate and Separation Proof
Verify the exact formulas:
- $\text{dist\_u1\_exit} = |L_1| - p_1$
- $\text{dist\_u2\_entry} = p_2 + r_2$
- Cumulative sequence separation along directed edges: $\text{sep}_{\text{next}} = \text{sep}_u + \text{len}(u) - \text{overlap}$.
- Prove that $\text{sep}$ is monotonically non-decreasing along all valid graph edges (confirm $\text{overlap} \le \text{len}(u)$ in production cDBG).
- If monotonicity could fail, identify the exact edge topology.

#### A3. Boundary Conditions
Inspect edge cases:
- $\text{sep} + \beta == \text{max\_insert}$ (must NOT be pruned!)
- $\text{sep} + \beta == \text{max\_insert} + 1$ (pruned)
- $\beta = 0$ (evidence absent)
- Very short reads ($< 31$ bp) or single-base unitigs.
- Coordinate overflow safety in integer additions.

#### A4. Production Counterexample Search
Actively attempt to construct a minimal directed graph counterexample where:
Strong competitor path pruned by $\beta$ + `SearchStatus::Complete` returned + Weak decoy committed.
If found, report as a P1 correctness blocker. If sound, state the mathematical proof and supporting invariants.
